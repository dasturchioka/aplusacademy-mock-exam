# Video Tutorial Files

This directory should contain the following video tutorial files:

- `listening-tutorial.mp4` - Tutorial for the Listening section
- `reading-tutorial.mp4` - Tutorial for the Reading section
- `writing-tutorial.mp4` - Tutorial for the Writing section

## Video Requirements

- **Format**: MP4
- **Controls**: The video player will only show a Play button, no other controls
- **Size**: Recommended resolution 1280x720 or higher
- **Duration**: Keep tutorials concise (2-5 minutes recommended)

## Usage

These videos are displayed in the start modal before each section begins. Users can:

- Click the "Play Tutorial" button to start/pause the video
- No other video controls (seek, volume, fullscreen) are available
- Videos are set to preload metadata only for faster loading

## File Placement

Place the video files directly in this directory:

```
cd-mock-exam/public/videos/
├── listening-tutorial.mp4
├── reading-tutorial.mp4
└── writing-tutorial.mp4
```

The videos will be accessible at:

- `/videos/listening-tutorial.mp4`
- `/videos/reading-tutorial.mp4`
- `/videos/writing-tutorial.mp4`
